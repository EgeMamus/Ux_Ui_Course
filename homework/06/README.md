# Homework 06 — Low-fidelity Wireframes

## Summary

Created low-fidelity wireframes for the Cross-border
Road Payments application, focusing on the main
user journey, responsive layouts and error handling.

## Work Completed

- Designed four main mobile wireframes:
  - S1: Trip and vehicle details.
  - S2: Road charges by country.
  - S3: Review online purchases.
  - S4: Payment results and remaining actions.
- Created a desktop adaptation of S2.
- Designed three critical alternative states:
  - Invalid user input.
  - No eligible online items.
  - Partial or unknown payment results.
- Created reusable wireframe components.
- Documented layout, navigation and accessibility decisions.
