# Homework 08 — Usability Testing & UI Guideline

## Summary

Conducted a small usability evaluation of the
Cross-border Road Payments prototype and documented
interface improvements and a mini UI guideline.

## Work Completed

- Prepared a usability test plan and consent briefing.
- Documented feedback from three anonymized users.
- Recorded task completion and assistance results.
- Identified and prioritized usability issues.
- Improved payment status guidance.
- Added a fixed footer for important navigation actions.
- Improved control border contrast.
- Created a mini UI guideline covering colors,
  typography, spacing, buttons and accessibility.

## Usability Test Results

- U1: Completed without help; found the navigation clear.
- U2: Completed without help; initially misunderstood
  the pending payment status.
- U3: Completed without help; requested calendar-based
  date selection.

According to the project owner, all three participants
completed the task without assistance.

Completion times were not measured.
The exact prototype version tested was not recorded.
