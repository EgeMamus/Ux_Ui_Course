# Homework 07 — Clickable Prototype

## Summary

Created a clickable low-fidelity prototype for the
Cross-border Road Payments application and
documented initial usability feedback.

## Work Completed

- Created eleven mobile prototype screens.
- Connected the main user journey from trip details
  to payment results and remaining actions.
- Added interactive date and vehicle selections.
- Designed country-specific road charge details.
- Implemented simulated payment status flows,
  including pending, failed and confirmed states.
- Added a recovery flow for retrying failed items.
- Documented a first usability trial reported
  by the project owner.

## Deliverables

- [Homework 07 — Figma Prototype](https://www.figma.com/design/KlHAl8ELM2WrHP8paV1o1A/Homework-7-Cross-border-Road-Payments-Clickable-Prototype)

## Testing Notes

The feedback is summarized rather than quoted verbatim.
Completion time and assistance were not recorded.

The feedback highlighted difficulties with finding
the Continue button and understanding when to
check a pending payment again.

## Limitations

The prototype uses fictional products and prices.
No real payments or provider integrations are included.
The proposed improvements have not yet been retested.
