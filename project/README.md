# Cross-border Road Payments — UX/UI Project

A UX/UI design project that helps drivers travelling
across multiple countries understand and manage road
charges, vignette requirements and payment statuses.

The project focuses on drivers travelling from Türkiye
to Hungary through Bulgaria and Serbia.

Current status: Ten weeks of UX/UI coursework
completed, including user research, interface analysis,
wireframes, interactive prototypes, usability testing,
design iterations and a final presentation.

Payments and products in the prototype are simulated.
No real payment integration is included.

## Project Limitations

- One initial user interview informed early research.
- Three participants provided usability feedback.
- Task completion times were not measured.
- The latest prototype changes have not been
  retested with participants.
- No live payments or external provider integrations
  are implemented.
